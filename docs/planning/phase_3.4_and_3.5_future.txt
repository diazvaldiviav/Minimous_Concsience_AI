## 🔧 Technical Architecture

### Hybrid Evaluation Strategy

The system employs a three-component hybrid approach:

1. **Semantic Similarity** (45% weight)
   - Uses sentence-transformers embeddings
   - Measures semantic coherence between states
   - Robust fallback to word overlap similarity

2. **Rule-based Analysis** (35% weight)
   - Goal coherence patterns
   - Emotional transition validation  
   - Confidence progression analysis
   - Memory integration assessment

3. **Contextual Continuity** (20% weight)
   - Structural consistency checks
   - Thematic coherence evaluation
   - Temporal consistency patterns

### Calibrated Decision Thresholds

```python
# Optimized for balanced precision/recall
self.coherent_threshold = 0.55    # Coherent classification
self.incoherent_threshold = 0.45  # Incoherent classification
# Ambiguous range: 0.45-0.55 (10% of decision space)
```

### Error Handling & Fallbacks

- **Primary**: Hybrid semantic + rule-based evaluation
- **Fallback**: Pure heuristic evaluation if hybrid fails
- **Error Recovery**: Graceful degradation with logging
- **Performance**: Multiple embedded caching layers
