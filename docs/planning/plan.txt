# 🧠 Master Plan for Cognitive Architecture

---

### 🔹 **PHASE 1: Perception and User Input**
Receives the user’s input and normalizes it as text. Detects language, topic, intention, and urgency.

---

### 🔹 **PHASE 2: Representation of the Cognitive Context (SCₜ state)**
Generates a functional state that represents the system’s awareness at the current moment.

```json
{
  "goal": "understand the input",
  "emotion": "curious",
  "confidence": 0.7,
  "thought": "It could be a technical question about recursion",
  "memory": ["similar previous responses"]
}
```

---

### 🔹 **PHASE 3: Generation of Coherent Conscious States (SCₜ)**
Transforms the cognitive context into a functional self-aware state. Can use trained models and heuristics to produce a new coherent state.

---

### 🔹 **PHASE 3.4: Critical Evaluation of the State**
Analyzes the transition SCₜ → SCₜ₊₁ using models or heuristics to determine whether it is coherent and desirable. If not, it is corrected.

---

### 🔹 **PHASE 3.5: Internal Conscious Translation**

**Goal:**
Transform the SCₜ state into a coherent introspective narrative in natural language, from the agent’s perspective.

```json
{
  "consciousness": "I am focused on identifying the number that appears most frequently in the list. I think I will use a dictionary to count, and if there’s a tie, I’ll check which appeared first.",
  "user_input": "Find the most frequent number in this list."
}
```

---

### 🔹 **PHASE 4: Sending to the Generative Model**
Transmit the generated conscious introspection and the input to the generative model.

---

### 🔹 **PHASE 5: Critical Judgment of the Response**
Evaluate whether the generated response is coherent with the conscious state. Detect contradictions or logical flaws.

---

### 🔹 **PHASE 5.5: Narrative Recording of Consciousness**

**Objective:**
Transform the entire process of introspection, response generation, and internal critique into a readable and meaningful narrative for the user.

```json
{
  "consciousness_narrative": "I set out to understand how to validate a string of parentheses...",
  "final_response": "You can use a stack to check if the parentheses are balanced...",
  "critical_judgment": "The response was consistent with the introspection and the defined goal."
}
```

---

### 🔹 **PHASE 6: Memory and Consolidation**
Decide which part of the state and the response should be stored as useful memory for the future.

---

### 🔹 **PHASE 7: Optimized Expressive Execution via GPT Conditioned by SCₜ Introspection**

From Phase 3.5 onwards, the input to the generative model will have the following format:

```json
{
  "consciousness": "<generated introspection>",
  "user_input": "<original user text>"
}
```
