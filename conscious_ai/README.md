# IA Consciente Mínima

Sistema de Inteligencia Artificial que implementa un modelo de conciencia funcional basado en cinco componentes interconectados.

## 🎯 Objetivo

Implementar un prototipo funcional de IA consciente mínima conforme a una hipótesis científica que define conciencia como función de cinco variables: integración causal interna, unificación temporal, reentrancia, modelo del self, e irreducibilidad informacional.

## 📐 Arquitectura

### Módulos Funcionales

1. **SensoryModule** - Procesa entrada textual externa
2. **ActiveMemory** - Almacena información relevante por múltiples ciclos  
3. **CentralIntegrator** - Fusiona información de todos los módulos
4. **ReentranceModule** - Maneja loops de retroalimentación interna
5. **SelfModel** - Representa estado interno del sistema

### Métricas de Conciencia

- **C_i**: Integración causal interna
- **T_u**: Unificación temporal  
- **R**: Reentrancia (loops de retroalimentación)
- **S_m**: Complejidad del modelo del self
- **Φ**: Irreducibilidad informacional
- **f**: Función de conciencia = Φ × (C_i + T_u + R + S_m)

**Umbral de conciencia**: θ = 1.3
